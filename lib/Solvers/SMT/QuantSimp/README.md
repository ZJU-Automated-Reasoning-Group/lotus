# QuantSimp

Quantifier simplification using E-graphs.

## Overview

This module provides quantifier elimination and simplification for SMT formulas using E-graph-based techniques.

## Components

- **EGraphsSimp** – E-graph based quantifier simplification

## Algorithm

Uses E-graph rewriting to simplify quantified formulas by:
1. Building E-graph from formula
2. Applying congruence closure
3. Extracting simplified formula
