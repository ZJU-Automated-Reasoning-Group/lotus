Command-Line Tools

Lotus provides command-line tools for alias analysis, CFL reachability, bug detection, IR querying, optimization, verification, and solver experiments.

This section focuses on the front-end binaries and tool families under tools/. The documentation is organized by subdirectory to match the source structure, but some pages also note when a tool family contains source-present experiments that are not built by default.

For a feature-oriented walk-through, see Tutorials and Examples and Bug Detection with Lotus.
